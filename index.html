为什么是 BeLight

今天向 AI 提问一件屏幕上的事，要经历：截图 → 保存 → 打开 AI → 上传 → 描述上下文 → 提问。BeLight 把六步压缩成两步。

😮‍💨 传统方式

  • 手动截图、找文件、上传
  • 反复切窗口，思路被打断
  • 用语言描述"我看到的东西在哪"
  • 每次问答都是一次 context switch

⚡ BeLight 方式

  • Alt+A，屏幕变暗，一圈即问
  • 悬浮窗就地出答案，看完即走
  • 画笔圈点，AI 精确理解你指的位置
  • 问答发生在工作流内部，零切换

核心特点

小、快、干净。做一件事，做到极致。

🎯

圈选即问

全局热键唤起，圈选屏幕任意区域，随手补一句问题，多模态大模型直接看图作答——无 OCR、无中间转换，原图直达。

🖌️

画笔标注

红圈、黄高亮、蓝箭头、绿序号四种标注。程序自动把标注坐标翻译成结构化语言注入提示词，AI 精确定位你指的地方。

🔀

双通道回答

API 通道：接入 OpenAI / Claude / Kimi，流式答案就地展示。网页通道：自动把截图+问题注入 Kimi / Copilot 网页版，在官方界面里继续深聊。

🪶

轻若无物

安装包小于 20 MB，常驻内存不到 50 MB，启动一秒内。托盘静默驻留，用时即来，不用时仿佛不存在。

🔒

隐私自决

密钥存系统钥匙串不落明文；历史记录仅存本地、可一键关闭或清除；截图只发给你自己选择的 AI 服务商。

🌍

中英双语 · 亮暗主题

界面语言、主题、字号、结果窗不透明度全部可调，设置即时生效。

三步上手

装好后驻留托盘，从第一次按键到拿到答案不超过十秒。

唤起圈选

任意界面按 Alt+A，屏幕变暗后拖出你想问的区域；可用画笔圈点重点，回车确认。

补一句问题

在圈选条里输入你的问题（也可以什么都不写），回车提交。

拿到答案

API 通道：悬浮窗流式出答案，可复制/重新生成/继续追问。网页通道：自动跳入 Kimi 或 Copilot 继续对话。

现在开始

下载安装，按一下 Alt+A，你就再也回不去截图-上传的老路了。
